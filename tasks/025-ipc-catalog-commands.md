## Задача

`#020` добавил `catalog`/`search`/`details`/`episodes` как методы `AppService` в `kino-ipc`, но
не выставил их наружу: в `src-tauri` нет `#[tauri::command]`-обёрток, они не зарегистрированы в
`build.rs`/`lib.rs`, нет capabilities/permissions, `ui/src/bindings.ts` их не содержит. Фронтенд
физически не может их вызвать. Нужны тонкие обёртки по образцу существующих команд в
`src-tauri/src/commands.rs` (`mirrors`/`session` и т.п., `State<'_, Service>` → вызов метода
`AppService` → `Result<T, IpcError>`), без новой логики.

## Ограничения

- Никакой новой логики — только `#[tauri::command] #[specta::specta]` обёртки, 1 в 1 сигнатура
  метода `AppService` (`catalog(kind, page)`, `search(query)`, `details(item)`,
  `episodes(details)`).
- Новые DTO не нужны — всё уже есть в `kino-ipc` (`MediaKindDto`, `MediaItemDto`,
  `MediaDetailsDto`, `EpisodeDto`).
- `src-tauri/build.rs` COMMANDS + `src-tauri/src/lib.rs` `collect_commands!` — добавить 4 новых.
- `src-tauri/capabilities/default.json` — добавить `allow-catalog`/`allow-search`/`allow-details`/
  `allow-episodes` (автогенерируемые `permissions/autogenerated/*.toml` не писать руками —
  появятся сами из `tauri-build` при сборке/проверке). Без `fs`/`shell`/`http`/`opener`.
- `cargo test -p kinobox-app export_bindings` — обновить `ui/src/bindings.ts`, закоммитить.
- `src-tauri/CRATE.md` — дополнить таблицу команд.
- Не запускать `cargo tauri dev`/`.app`/`cargo run -p kinobox-app`.
- Не собирать `libmpv`/`mpv` локально (нет x86_64-бутылки на этой машине) — линковка/`export_bindings`
  с реальным mpv проверяется только через CI. Не гонять тесты в цикле — один прогон каждой
  проверки, зелёно — готово, красно — чини осознанно.
