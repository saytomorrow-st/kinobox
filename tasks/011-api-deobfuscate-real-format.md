## Задача

Привести `deobfuscate` (появилась в #006) к реальному формату строки потоков. На странице фильма (kvk.pub, 2026-11-14) префикса `#h` нет, а качество записано так: `[480p]U1 or U2 or U3 or U4,[720p]...`. Внутри качества четыре адреса через ` or `: два HLS-адреса с суффиксом `:hls:manifest.m3u8` и два прямых `.mp4` на двух разных хостах CDN. Метка премиум-качества содержит HTML: `[<span class="pjs-prem-quality">1080p Ultra<img ...></span>]`.

## Ограничения

- Разделитель адресов внутри качества: ` or `. Из метки вырезать HTML-теги.
- Изменение `StreamQuality` в `kino-core` публичное: добавить `premium: bool`, `hls: Option<Url>`, `fallbacks: Vec<Url>`; `url` остаётся прямым mp4. Обновить `CRATE.md` обоих крейтов в том же коммите.
- Премиум-качества не скрывать и ничего не обходить: отдавать как данные с флагом `premium`.
- Ветку `#h` сохранить. Для неё есть два противоположных свидетельства: библиотека `hdrezka-api` деобфусцирует всегда, а `hdrezka` по умолчанию выключает деобфускацию. Токены по `ARCHITECTURE.md`, список токенов у обеих библиотек совпадает.
- В тестах не использовать реальные адреса потоков: в них подписи с временной меткой. Хосты заменить на `cdn.example.com` и `cdn2.example.com`.
- Не копировать код библиотек, использовать только описание формата.

## Готово когда

- `cargo test -p kino-core -p kino-api`: реальная форма (4 адреса, метка с HTML, премиум-качество), старые тесты деобфускации, пустые и битые входы
- Руками: `cargo run -p kino-api --example deobfuscate -- '[360p]https://cdn.example.com/a.mp4:hls:manifest.m3u8 or https://cdn.example.com/a.mp4,[720p]...'` печатает качества с mp4, hls и признаком premium
