## Задача

`deobfuscate.rs`: из ответа `url` получить `Vec<StreamQuality>`. Алгоритм строго из `ARCHITECTURE.md`: префикс `#h`, разделитель `//_//`, удаление известных мусорных токенов, base64. Затем разбор формата `[360p]url,[720p]url`. Необфусцированный `url` (без `#h`) разбирается напрямую.

## Ограничения

- Токены мусора лежат константой в одном месте.
- Ошибка декодирования возвращает `KinoError`, без паники и без `unwrap`.
- Нет сетевых вызовов, чистая функция.
- Не придумывать новые токены. Если реальный ответ не декодируется, `status: blocked` и вопрос заказчику.

## Готово когда

- `cargo test -p kino-api deobfuscate`: обфусцированный и обычный вход, пустой вход, битый base64, несколько качеств в одной строке
- `CRATE.md` обновлён
