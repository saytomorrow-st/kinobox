## Задача

Главный экран каталога в стиле Apple TV: hero-карусель сверху, горизонтальные ряды постеров под
ней, фокус-навигация стрелками (клавиатура — мышь на macOS вторична, но не исключается). Данные —
через новые команды `catalog`/`search` из #020.

## Ограничения

- Дизайн-система из `ARCHITECTURE.md` (раздел «Дизайн-система»): фон `#000000`, акцент `#FA233B`,
  скругления, отступы, типографика — строго соблюдать, не изобретать свою палитру.
- Focus lerp-переход (не скачок), ряд 10×2 с shelf push при фокусе — минимально работающая версия
  допустима (можно упростить анимацию, если полная версия рискует сроком), но сам принцип
  (постепенный, не мгновенный фокус) обязателен.
- Минимальные capabilities/CSP не трогать сверх необходимого — экран использует только уже
  зарегистрированные команды.
- Постеры — `img-src 'self' data:` уже разрешён в CSP; если нужны внешние хосты (постеры с
  зеркала), придётся расширить `img-src` в `tauri.conf.json` — явно решить и задокументировать (это
  изменение CSP, согласовать с ограничением «строгий CSP» из `AGENTS.md`/памяти проекта: расширять
  только на конкретные необходимые источники, не на `*`).
- Код в `ui/src/screens/`, `ui/src/components/` по образцу `LoginScreen.tsx`/`MirrorsPanel.tsx`.

## Заметки

Зависит от #020 (команды каталога). Не зависит от плеера (#017/#018/#019/#021) — можно делать
параллельно. Перед началом — явно решить вопрос с `img-src` в CSP для постеров зеркала (см.
ограничения) и зафиксировать решение здесь, в «Заметках».

**CSP `img-src` — решено.** Проверено через `crates/kino-api/src/parse/details.rs`
(`img[itemprop="image"]` + `resolve_url`) и единственную доступную фикстуру
`crates/kino-api/tests/fixtures/film_85038.html` (зеркало `kvk.pub`): реальный `src` постера —
`https://st.hdrezka.ac/i/...jpg`, отдельный статический CDN-домен, не совпадающий ни с доменом
зеркала (`kvk.pub`), ни с каноничным `og:site_name` (`rezka.ag`). Добавлен конкретный домен
`https://st.hdrezka.ac` в `img-src` (`csp` и `devCsp` в `src-tauri/tauri.conf.json`), без wildcard.
Остаточный риск: если у HDrezka есть другие CDN-поддомены, не встретившиеся в единственной
фикстуре, их постеры будут молча не грузиться (битая картинка), без краша — приемлемая деградация,
пересмотреть при обнаружении на практике.

**Реализация.** `ui/src/catalog-store.ts` — новый zustand-стор (`load`/`loadMore`/`search`,
дедупликация параллельных вызовов, пагинация с `page` от 1, `search` без пагинации). `ui/src/api.ts`
расширен методами `catalog`/`search`. `ui/src/screens/MainScreen.tsx` переписан в тонкий экран,
рендерящий новый `ui/src/components/CatalogScreen.tsx` (контейнер: 2D-фокус `{row,col}`,
обработка стрелок/Enter через `window.addEventListener("keydown")`, разбиение на ряды по 10
колонок). Чистые презентационные `ui/src/components/HeroBanner.tsx` (16:9-баннер из `items[0]`) и
`ui/src/components/PosterRow.tsx` (постер-карточки, `focusedIndex` → `scale-105`/`ring-2
ring-accent`). Переход фокуса и shelf-push нижних рядов — через Tailwind
`transition-transform duration-200` (CSS, не JS rAF-цикл) — удовлетворяет требованию
«постепенный, не мгновенный» без JS-анимационного движка. Enter на карточке — пока no-op-стаб
(экран деталей #023 ещё не существует); открытие через клик/Enter будет подключено в #023.

**Проверено:** `pnpm --dir ui typecheck && pnpm --dir ui test && pnpm --dir ui build && pnpm --dir ui lint`
— все зелёные (50 тестов, включая 17 новых для `catalog-store.ts`).

**Модели:** `claude-sonnet-5` — архитектурный клей (api.ts/store.ts/catalog-store.ts, CSP-решение,
ревью); `deepseek-v4-pro` — компоненты экрана (CatalogScreen/HeroBanner/PosterRow,
focus-навигация); `deepseek-v4-flash` — тесты `catalog-store.test.ts` (17 тестов), в процессе
написания нашёл и исправил реальный баг в `search()`: пустой запрос делегировался в `load()` уже
после установки `loading:true`, что из-за собственного guard'а `load()` оставляло стор навечно
в `loading:true`. Исправлено — проверка на пустую строку выполняется раньше установки `loading`.
