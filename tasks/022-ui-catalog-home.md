## Задача

Главный экран каталога в стиле Apple TV: hero-карусель сверху, горизонтальные ряды постеров под
ней, фокус-навигация стрелками (клавиатура — мышь на macOS вторична, но не исключается). Данные —
через новые команды `catalog`/`search` из #020.

## Ограничения

- Дизайн-система из `ARCHITECTURE.md` (раздел «Дизайн-система»): фон `#000000`, акцент `#FA233B`,
  скругления, отступы, типографика — строго соблюдать, не изобретать свою палитру.
- Focus lerp-переход (не скачок), ряд 10×2 с shelf push при фокусе — минимально работающая версия
  допустима (можно упростить анимацию, если полная версия рискует сроком), но сам принцип
  (постепенный, не мгновенный фокус) обязателен.
- Минимальные capabilities/CSP не трогать сверх необходимого — экран использует только уже
  зарегистрированные команды.
- Постеры — `img-src 'self' data:` уже разрешён в CSP; если нужны внешние хосты (постеры с
  зеркала), придётся расширить `img-src` в `tauri.conf.json` — явно решить и задокументировать (это
  изменение CSP, согласовать с ограничением «строгий CSP» из `AGENTS.md`/памяти проекта: расширять
  только на конкретные необходимые источники, не на `*`).
- Код в `ui/src/screens/`, `ui/src/components/` по образцу `LoginScreen.tsx`/`MirrorsPanel.tsx`.

## Готово когда

- `pnpm --dir ui typecheck && pnpm --dir ui test && pnpm --dir ui build && pnpm --dir ui lint`
  зелёные
- Открытие карточки (клик/Enter на постере) ведёт на экран деталей из #023

## Заметки

Зависит от #020 (команды каталога). Не зависит от плеера (#017/#018/#019/#021) — можно делать

ограничения) и зафиксировать решение здесь, в «Заметках».
