## Задача

Окно входа в стиле диалога «Требуется вход» из Apple TV: тёмное окно с vibrancy, иконка приложения слева, заголовок, пояснение, поля email и пароль, «Отменить» и «Войти». Список зеркал и их проверка встроены в окно (раскрывающийся блок «Зеркала»).

## Ограничения

- Дизайн-система из `ARCHITECTURE.md` (акцент `#FA233B`, SF Pro, без видимых рамок и разделителей).
- Пароль только в локальном состоянии поля, очищается после отправки, в логи и в глобальный стор не попадает.
- «Отменить» закрывает приложение: вход обязателен.
- Клавиатура: Enter входит, Esc отменяет, Tab по полям.

## Готово когда

- Первый запуск без данных в Keychain показывает окно входа
- Неверный пароль показывает текст ошибки сайта, поля остаются
- Блок зеркал показывает состояние каждого зеркала и кнопку «Проверить»
