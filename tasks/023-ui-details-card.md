## Задача

Карточка деталей произведения (модалка на весь экран поверх каталога): постер, описание, жанры,
год, страны, длительность, выбор перевода, для сериалов — сезоны/серии, кнопка ▶ запускающая плеер
(#024). Данные — `details`/`episodes` из #020.

## Ограничения

- Дизайн по `ARCHITECTURE.md`: «постер на весь экран, затемнение, кнопка ▶, выбор
  качества/перевода/субтитров» — выбор качества/субтитров физически происходит в плеере (#024),
  здесь — выбор перевода и (для сериалов) серии перед запуском.
- Пароль/сессия сюда не имеют отношения — не трогать `session-store.ts`.
- Код в `ui/src/screens/` или `ui/src/components/` по образцу существующих экранов.
- Модалка открывается и закрывается без потери состояния каталога за ней (скролл/фокус ряда
  сохраняются при возврате).

## Готово когда

- `pnpm --dir ui typecheck && pnpm --dir ui test && pnpm --dir ui build && pnpm --dir ui lint`
  зелёные
- Кнопка ▶ с выбранным переводом (и серией, если сериал) передаёт управление в #024

## Заметки

Зависит от #020 (DTO деталей/серий), #022 (точка входа — клик по постеру). Не зависит от плеера
напрямую, но кнопка ▶ становится полезной только после #021/#024.
