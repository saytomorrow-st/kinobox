## Задача

Исправить детектор защитного челленджа в `client.rs` (появился в #004). Реальный Anubis отвечает статусом 200, ставит куки `techaro.lol-anubis-*` и отдаёт страницу с заголовком «Проверяем, что вы не бот!». Сейчас клиент ищет маркеры только при 403 и 503, поэтому принимает такую страницу за обычный ответ.

## Ограничения

- Не искать слово «anubis» в теле: на обычной странице оно может встретиться (например, название фильма). Признаки только такие: имя куки в `Set-Cookie` начинается с `techaro.lol-anubis`, либо `<title>` содержит «Проверяем, что вы не бот» или «Making sure you're not a bot».
- Челлендж даёт `KinoError::Challenge` без retry при любом статусе.
- PoW не реализуем. Решение о нём принимает заказчик, модель для него `claude-opus-5-5`.
- Файлы: `crates/kino-api/src/client.rs`, `CRATE.md`.

## Готово когда

- Тесты wiremock: 200 с кукой Anubis даёт `Challenge`; 200 с заголовком страницы даёт `Challenge`; 200 с обычной страницей, где в тексте есть «Anubis», проходит; старые тесты на 403 и 503 остаются зелёными
- Руками: `cargo run -p kino-api --example fetch -- https://rezka.ag/` печатает ошибку `Challenge` и завершается с кодом 1 (результат зависит от IP, без VPN проверено 2026-11-14)
