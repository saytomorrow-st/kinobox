## Задача

Экран плеера (окно `player-controls` из #021): контролы поверх видео, рисуемого `libmpv` в соседнем
окне `player` — прогресс-бар, play/pause, перемотка, громкость, выбор качества/перевода/субтитров,
кнопка закрытия. Команды — `playerLoad/Play/Pause/Seek/SetQuality/SetVolume/Stop` из #021, события
прогресса подписка через `tauri::Event`.

## Ограничения

- Контролы в прозрачном окне, клики вне зоны контролов не должны мешать видео под ними (см.
  архитектурное решение в `ARCHITECTURE.md`, раздел «Встраивание libmpv в окно») — зона кликабельности
  явно ограничена компонентами контролов, а не всем окном.
- Контролы скрываются при неактивности (несколько секунд без движения мыши/нажатий) и появляются
  обратно по движению — стандартное поведение видео-UI, минимально реализовать.
- Никакого DRM/обхода оплаты — плеер показывает только то, что отдаёт `streams` для публичной
  страницы.
- Визуально проверить через живой запуск нельзя — агент/subagent не запускают GUI. Юнит-тесты на
  логику контролов (форматирование времени, расчёт процента прогресс-бара, debounce скрытия) —
  обязательны и являются основной проверкой здесь.
