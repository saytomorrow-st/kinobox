## Задача

Команды `kino-ipc` для окна входа: состояние сессии, вход, выход, список зеркал с проверкой, ручное зеркало. Логика в обычном слое сервиса без Tauri (тестируется wiremock и `MemorySecretStore`), поверх неё тонкие `tauri::command` с типами для specta.

## Ограничения

- Пароль приходит в команду входа один раз и нигде не хранится: ни в состоянии, ни в событиях, ни в `Debug`, ни в ошибках для UI.
- В Keychain данные пишутся только после успешного входа (`login_and_remember`).
- Не менять `kino-api` без необходимости; если нужен метод, добавить минимально и обновить `CRATE.md`.
- Не обходить Anubis: зеркало с челленджем показывается в списке как недоступное.

## Готово когда

- `cargo test -p kino-ipc` зелёный, `cargo clippy --workspace --all-targets -- -D warnings` зелёный, обе архитектуры собираются
- `kino-ipc/CRATE.md` описывает команды и DTO

## Заметки

Первый запуск без сохранённых данных показывает окно входа. Сохранённые данные подхватываются молча.
