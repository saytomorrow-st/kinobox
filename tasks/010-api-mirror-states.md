## Задача

Переделать пробу в `MirrorPool` (появился в #005). Сейчас страница входа считается мёртвым зеркалом, но заказчик подтвердил, что часть зеркал показывает форму входа, и приложение работает только со входом. Нужны четыре состояния: `Open`, `NeedsLogin`, `Challenge`, `Dead` (таблица в `ARCHITECTURE.md`, раздел «Зеркала»).

## Ограничения

- `NeedsLogin` считается живым зеркалом. `Challenge` и `Dead` пропускаются.
- Куки привязаны к домену, поэтому `resolve()` возвращает зеркало вместе с признаком, нужен ли вход.
- Список известных зеркал по умолчанию: `https://kvk.pub/`, `https://rezka.fi/`. `rezka.si` не добавлять, пока заказчик не подтвердит, что домен официальный.
- Состояние `Challenge` определяется кодом из #009, дублировать его не нужно.
- `MirrorStore` не менять.
- Файлы: `mirrors.rs`, `examples/mirrors.rs`, `CRATE.md`.

## Готово когда

- Тесты wiremock на все четыре состояния, включая 200 со страницей входа и 200 с Anubis
- Руками: `cargo run -p kino-api --example mirrors -- --known https://kvk.pub/ --known https://rezka.fi/` печатает `LOGIN` для обоих зеркал, если у вас нет сессии (без VPN проверено 2026-11-14)

## Заметки

Зависит от #009. Неясно, принимает ли `standby-rezka.tv` вход напрямую: он отдаёт форму без редиректа. Выяснится в #012.

2026-11-14: проба зеркал переделана под четыре состояния (`Open`, `NeedsLogin`, `Challenge`, `Dead`). 72 теста `kino-api`, `fmt`/`clippy`/обе архитектуры зелёные.
- Страница входа теперь живое зеркало (`NeedsLogin`), `resolve()` и `add_manual()` возвращают `ResolvedMirror { url, state }`. Челлендж и мёртвые зеркала пропускаются.
- Список по умолчанию: `kvk.pub`, `rezka.fi`. `rezka.si` не добавлен: заказчик не подтвердил домен.
- Порядок в `known` определяет пользователь: `NeedsLogin`-зеркало раньше `Open`-зеркала в списке будет выбрано первым.
- `standby-rezka.tv` без редиректа не считается зеркалом (в статусе `NeedsLogin` с пометкой). Принимает ли он вход напрямую, не проверено, выяснится в #012.
- Пример `mirrors` без аргументов без VPN (2026-11-14): `LOGIN` для `kvk.pub` и `rezka.fi`, `active: https://kvk.pub/ (login required)`.
- Пример делает по два GET на адрес (`health_check` и `resolve`).
- В `ARCHITECTURE.md` проба описана как «HTTP HEAD / главная», в коде GET. Поправить при ближайшей правке документа.
